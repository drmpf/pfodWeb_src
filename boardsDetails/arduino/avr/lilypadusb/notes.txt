Board: LilyPad Arduino USB (avr/lilypadusb, split off avr/leonardo)
Date: 2026-07-14

Reason for split: LilyPad Arduino USB runs at 3.3V/8MHz, unlike its
former "leonardo" directory siblings (Leonardo/Esplora/Leonardo ETH),
which run 5V/16MHz. A single shared board.json cannot correctly state
one ADC reference voltage for both groups, so a new self-contained
variant directory was created: pins_arduino.h is a one-line #include of
../leonardo/pins_arduino.h (identical 32U4 pin map), with its own
board.json overriding only adc.defaultRefVolts to 3.3V.
boards.txt's LilyPadUSB.build.variant was repointed from "leonardo" to
"lilypadusb".

Sources consulted:
- docs.arduino.cc/retired/boards/lilypad-arduino-usb (official) —
  confirms 3.3V/8MHz operation and an onboard LED on pin 13 that
  "breathes" during the bootloader and is otherwise user-controllable.
- arduino.cc/en/Guide/ArduinoLilyPadUSB — corroborates the same D13 LED.

Per-pin findings:
- D13 (LED_BUILTIN) — confirmed onboard status LED, active-high. Not on
  this 32U4 pin map's SPI bus (SPI moved to D14-D17), so no dual-role
  caveat needed. Tagged ["digital_output","pwm_output","led_high"].
- No other dedicated hardware found beyond the D13 LED.

Summary: LilyPad Arduino USB — split from "leonardo" for correct 3.3V
ADC reference voltage; D13 onboard LED confirmed and tagged active-high.
