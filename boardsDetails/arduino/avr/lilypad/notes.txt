Board: LilyPad Arduino (avr/lilypad, split off avr/standard)
Date: 2026-07-14

Reason for split: LilyPad Arduino runs at 3.3V/8MHz, unlike its former
"standard" directory siblings (Uno/ATmegaNG/Diecimila/Uno Mini), which
all run 5V/16MHz. A single shared board.json cannot correctly state one
ADC reference voltage for both groups, so a new self-contained variant
directory was created: pins_arduino.h is a one-line #include of
../standard/pins_arduino.h (identical AVR pin map), with its own
board.json overriding only adc.defaultRefVolts to 3.3V.
boards.txt's lilypad.build.variant was repointed from "standard" to
"lilypad".

Sources consulted:
- arduino.cc/en/Main/ArduinoBoardLilyPad (official) — confirms 3.3V/8MHz
  operation and "one LED is soldered to board on pin 13".
- General web search corroborating the same onboard-LED-on-D13 fact.

Per-pin findings:
- D13 (PIN_SPI_SCK / LED_BUILTIN) — confirmed onboard status LED,
  active-high, soldered to the board. Same classic Arduino pin-13
  LED+SCK dual role as the standard-family boards — not a bug. Tagged
  ["digital_output","pwm_output","led_high"].
- No other dedicated hardware found; LilyPad exposes bare sew-tap pads
  for all other pins, no onboard sensors beyond the D13 LED.

Summary: LilyPad Arduino — split from "standard" for correct 3.3V ADC
reference voltage; D13 onboard LED confirmed and tagged active-high.
