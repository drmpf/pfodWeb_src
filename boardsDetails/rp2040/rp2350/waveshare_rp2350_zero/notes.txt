PER-PIN REASONING
- GPIO16 (PIN_NEOPIXEL): Onboard WS2812 addressable RGB LED. Confirmed via this board's own
  pins_arduino.h (#define PIN_NEOPIXEL (16u)), WebSearch results referencing the Waveshare wiki/
  product page and TinyGo, and Zephyr Project's official board documentation. This is the board's
  ONLY onboard visual indicator — Zephyr docs explicitly state no separate plain LED is documented,
  consistent with the already-confirmed RP2040-Zero sibling (same "Zero" form-factor pattern, same
  GPIO16 NeoPixel pin). Tagged output-only: "capabilities": ["digital_output", "led_neopixel"] —
  matches the established RP2040-Zero precedent
  (variants/rp2040/rp2040/waveshare_rp2040_zero/board.json GPIO16) and the repo-wide
  vccgnd_yd_rp2040/board.json GPIO23 NeoPixel-tagging convention. pwm_output omitted since WS2812 is
  a bit-serial protocol data line, not a PWM-dimmable output. digital_input dropped since the pin is
  write-only in normal NeoPixel use.
- No PIN_LED alias exists anywhere in this board's pins_arduino.h — nothing to tag as
  led_high/led_low. generic_full/common.h's LED_BUILTIN is conditional on PIN_LED being defined,
  which it is not here.
- No collision check needed for GPIO16 against SPI/Wire/Serial bus pins — this board's SPI0
  (2,3,4,5), SPI1 (12,13,14,15), Wire0 (4,5), Wire1 (26,27), Serial1 (0,1), and Serial2 (8,9)
  definitions never touch GPIO16, so no build_boards.js bus-auto-append collision exists on the
  NeoPixel pin (unlike the adafruit_feather_scorpio precedent case).
- BOOT button: standard RP2350 bootloader-entry button, out of scope per task instructions (same
  BOOTSEL rationale already established in rpipico/board.json and reused for the RP2040-Zero
  sibling — not a normal GPIO digitalRead(), and this board's pins_arduino.h declares no alias for
  it anyway).
- RESET/RUN button: hardware reset, not represented by any pins_arduino.h alias — no GPIO to tag.
- No other user-accessible buttons found in any consulted source.
- inputOnlyGpios / pinNotes / pwm / dac / adc all left at chip-level defaults (12-bit ADC, 8-bit
  analogWrite, no DAC) — this board's pins_arduino.h declares no board-specific analog aliases
  beyond ../generic_full/common.h.
