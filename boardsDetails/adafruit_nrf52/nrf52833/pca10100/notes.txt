SOURCES CONSULTED
=================
1. This repo's own Adafruit_nrf52/variants/pca10100/variant.h — byte-
   for-byte identical pin layout to the nRF52840 sibling DK (pca10056),
   confirmed via diff. Same 4 LEDs/4 buttons/dual-UART/SPI/Wire/QSPI
   layout.
2. WebSearch: confirmed nRF52833 has a native full-speed 12 Mbps USB 2.0
   device controller, same capability class as nRF52840 (unlike
   nRF52832, which has none) — this was necessary to verify since this
   board's variant.h being byte-identical to pca10056's could otherwise
   have been a vendor copy-paste-without-adjusting-for-a-USB-less-chip
   bug (the exact class of thing this session already found once, on
   the Seeed XIAO nRF52840 Plus's TX/RX aliasing). Confirmed genuine:
   Serial really is native USB-CDC here too, matching the file as
   written.

PARSER-LEVEL FINDING — REQUIRED A SOURCE EDIT

— see that board's notes.txt for the full mechanism write-up. Same fix
applied: both `static const uint8_t A6/A7 = ...` lines deleted outright
from this repo's copy.

DECISIONS
=========
Identical to pca10056 (nRF52840 DK) — see that board's notes.txt for
the full per-pin reasoning. TAGGED: GPIO13-16 (LED1-4) led_low, GPIO11/
12/24/25 (BUTTON1-4) button. KEPT available: A0-A5, AREF, Serial1/2,
SPI, Wire. NOT EXPOSED: QSPI flash, NFC1/NFC2 (#define-only).
