PARSER-LEVEL FINDING — REQUIRED A SOURCE EDIT
==============================================
variant.h declares `#define PIN_A7 (0xff)` — a sentinel meaning "no A7
channel exists on this board" (the line's own comment: "to compile with
Firmata library") — then `static const uint8_t A7 = PIN_A7;`.
build_boards.js's alias-scanning regex only recognizes DECIMAL numeric
literals; confirmed by direct test that it parses "0xff" as decimal "0"
(matches the leading "0", stops at "x"), which would have silently
resolved this alias to a phantom "A7 (GPIO0)" pin — GPIO0 is genuinely
unrelated (PIN_SERIAL1_RX on this board) and has no other alias, so the
phantom would not even collide visibly with something already named,
making it easy to miss. FIX: deleted the `static const uint8_t A7 = ...`
line outright from this repo's copy (not commented out — this parser has
no C-comment awareness, confirmed pattern from earlier XIAO nRF52840
work this session). This affects 3 other boards in this family
identically (feather_nrf52840_sense_tft, pca10056, pca10100 — the
latter two also sentinel A6 the same way) — each has the identical fix
applied in its own pins_arduino.h, documented in its own notes.txt.

DECISIONS
=========
TAGGED: GPIO3 (PIN_LED1/LED_BUILTIN — single-color LED, both RED/BLUE
alias names point at the same physical pin, not an RGB LED) led_high,
GPIO4 (PIN_BUTTON1) button.

NOT TAGGED (established precedent, not a gap): DotStar data/clock
(GPIO8/6) — see sources above; also already invisible by default since
#define-only.

KEPT available: A0-A6 (GPIO14-20), SPI bus (GPIO5,23-25), Wire bus
(GPIO21-22) — no confirmed dedicated consumer.

NOT EXPOSED: QSPI flash (GPIO26-31), all #define-only.

NOT GUESSED: LED polarity from the family-wide spot-check; button from
an unambiguous vendor macro; DotStar non-tagging from established
in-repo precedent, not a fresh judgment call.

SUMMARY: 32 total Arduino pin indices (0-31, A7/GPIO0-phantom bug fixed
at the source); 2 tagged (1 LED, 1 button); A0-A6/SPI/Wire kept
general-purpose; DotStar/QSPI never appear (unaliased #define-only).
