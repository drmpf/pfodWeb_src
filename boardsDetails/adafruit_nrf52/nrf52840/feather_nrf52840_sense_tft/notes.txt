DECISIONS
=========
TAGGED: GPIO13 (PIN_LED1) led_high, GPIO8 (PIN_NEOPIXEL) led_neopixel,
GPIO3 (PIN_BUTTON1) button.

EXCLUDED (capabilities: [], by analogy to the same-vendor ESP32-S3
Feather TFT precedent, since this board's own SPI_INTERFACES_COUNT=1
means there is no separate dedicated display bus to fall back on the
way CLUE has): the entire default SPI bus — GPIO5 (SS), GPIO24 (MISO),
GPIO25 (MOSI), GPIO26 (SCK).

KEPT available: A0-A6 (GPIO14-20, including A6/VBAT — no confirmed
enable-sequencing pin, so treated as a plain battery-monitor analog
input per this family's standard policy), Wire bus (GPIO22-23, hosting
the onboard LSM6DS3TR-C IMU and PDM microphone's power gate, kept
general-purpose per this repo's established "general bus" policy).

NOT EXPOSED: NEOPIXEL_POWER (GPIO7), TFT DC/RST/LITE (GPIO36-38), mic
(GPIO33/34), PIN_LSM6DS3_IRQ (GPIO4), PIN_SENSOR_POWER (GPIO21), QSPI
flash (GPIO27-32), NFC1/NFC2 (GPIO39/40) — all #define-only.

annotates each Arduino index with the same physical address AND a
plain-English label) to translate between the two.

RESULT: every single decision in this board's board.json is now
CONFIRMED, not just analogized:
- LED_PRIMARY_PIN=P0.11 = variant.cpp's D13 ("LED1") = this repo's
  GPIO13, tagged led_high. Matches exactly.
- LED_NEOPIXEL=P1.08 + NEOPIXEL_POWER_PIN=P1.02 = variant.cpp's D8
  ("NeoPixel") and D7 ("Neopixel Power") = this repo's GPIO8/GPIO7.
  Matches exactly.
- BUTTON_DFU=P1.06 = variant.cpp's D3 ("Button") = this repo's GPIO3,
  tagged button. Matches exactly.
- DISPLAY_VSENSOR_PIN=P1.07 = variant.cpp's D21 ("Sensor Power") = this
  repo's GPIO21 (PIN_SENSOR_POWER, also gates the PDM mic per this
  board's own variant.h). Matches exactly.
- DISPLAY_PIN_SCK=P0.26 and DISPLAY_PIN_MOSI=P0.05 — THE DECIDING FACT:
  these are the IDENTICAL physical addresses as variant.cpp's D26 ("SPI
  SCK") and D25 ("SPI MOSI") — i.e. this board's DEFAULT SPI bus and
  the bootloader's own TFT display driver genuinely use the exact same
  physical pins. This is no longer an analogy to a different chip
  family's product line — it's now DIRECTLY CONFIRMED for this exact
  board that the SPI bus is TFT-dedicated. The GPIO5/24/25/26 exclusion
  decision was correct.
- DISPLAY_PIN_CS=P1.05, DC=P1.01, RST=P1.03, BL=P0.27 = variant.cpp's
  D35/D36/D37/D38 (TFT CS/DC/Reset/Backlight) = this repo's PIN_TFT_CS/
  DC/RST/LITE. Matches exactly (all already correctly invisible,
  #define-only).
