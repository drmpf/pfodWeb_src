ANALYSIS / DISCREPANCY FOUND
-----------------------------
This board's pins_arduino.h claims GPIO2/13/14/15 (SS/MOSI/MISO/SCK) are
an onboard "SD card slot" — but LilyGO's own official pinmap.md
documentation shows SD MISO/MOSI/SCLK/CS as N/A on every single T-Watch
variant (no official product has an onboard SD card at all), and
separately documents GPIO13 specifically as "IR Send" (an IR LED
transmitter) for the T-Watch2020 V1 revision this board most closely
matches. This is a genuine conflict between two first-party sources: the
board's own (Espressif-merged) pins_arduino.h vendor comment vs. LilyGO's
separate official hardware library documentation.

Per this repo's established policy for such conflicts ("When independent
research conflicts with the board's own file, trust the file and apply
only the corroborated parts" — see elecrow_crowpanel_7 precedent), the
GPIO2/13/14/15 exclusion is KEPT UNCHANGED. Rationale: regardless of
which first-party claim is literally correct (SD-SPI-SS vs. IR-transmit
for GPIO13), BOTH describe genuinely dedicated, non-general-purpose
onboard hardware — so the practical exclusion outcome is the same either
way, and no guess is needed to decide between them. This is recorded
honestly as UNCONFIRMED-BUT-KEPT, not claimed as independently verified.

CORRECTION APPLIED: TFT display bus (GPIO5/12/18/19/27) was NEVER
excluded by any prior pass, because this vendor's own pins_arduino.h
never declares MOSI/SCLK/DC/CS/BackLight via any `static const` alias at
all for this board (the T-Watch's TTGO.h library, not the Arduino-core
pins_arduino.h, owns the TFT wiring) — so build_boards.js's regex parser
had nothing to find, and no manual researcher had checked for it either
in the prior "dedicated-hardware" audit pass. LilyGO's own official
pinmap.md confirms GPIO5(CS)/12(BackLight)/18(SCLK)/19(MOSI)/27(DC) are
the ST7789 TFT's dedicated SPI/control bus on every T-Watch variant that
has a display at all (i.e. all except T-Block). These 5 GPIOs are now
EXCLUDED from chipGpios (removed), and GPIO5/GPIO12's pinNotes entries
(strapping-pin notes inherited from the chip-level default) were removed
along with them, matching this repo's established precedent (an excluded
GPIO should not carry an orphaned pinNote).

CONFIRMED, NO CHANGE:
- GPIO23/32/38 (FT6236 touch SDA/SCL/INT): exact match to pinmap.md.
  Stays excluded.
- GPIO35/37/39 (AXP192/PCF8563/BMA423 interrupts): exact match to
  pinmap.md. Stays excluded.
- GPIO33/34 (GPS/LoRa or SIM800L UART, bottom-plate dependent): matches
  pinmap.md's "GPS/LoRa TX/RX" and "SIM800L TX/RX" rows (same GPIOs
  regardless of which accessory is installed). Stays excluded.
- GPIO21/22 (SENSOR SDA/SCL): pinmap.md confirms this is the SAME shared
  bus used by BMA423 AND PCF8563 across every variant ("SENSOR SDA/SCL"
  row, identical value on every column) — genuinely a shared/multi-drop
  bus, not exclusively dedicated. Stays available, unchanged.
- GPIO36 (BUTTON on 2019 variants, N/A on 2020 V1): CONFIRMED correct
  as-is (kept, untagged) — official pinmap.md + TTGO.h both independently
  state the button was removed/unused in the 2020 V1 revision that this
  board's GPS/LoRa wiring identifies it as. If this were actually a 2019
  board, GPIO36 would need a "button" tag — but the evidence points to
  2020 V1, so no tag is applied. Documented so a future reviewer can
  revisit if the variant identification above is ever found to be wrong.
- GPIO4 (MOTOR on T-Watch2020 V1 per pinmap.md): NOT excluded. TTGO.h's
  own source comment ties this pin specifically to an optional SIM868
  bottom-plate accessory ("JUST ONLY SIM868"), not a fixed onboard
  actuator on the core watch module — left unchanged per the "don't
  guess when evidence is conditional/ambiguous" policy. If a future
  reviewer confirms this specific board variant always ships with the
  SIM868 plate, this should be revisited as a probable exclusion.

RESULT: 5 GPIOs (5,12,18,19,27) newly excluded as the confirmed onboard
TFT display bus — a genuine correction (omission fix), not previously
flagged. All previously-existing exclusions (touch, PMU/RTC/accel

claimed as verified. GPIO36 (button) and GPIO4 (motor) both left
unchanged, backed by real vendor-documented reasoning either way.
