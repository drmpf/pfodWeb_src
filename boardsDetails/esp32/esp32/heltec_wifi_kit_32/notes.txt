Board: heltec_wifi_kit_32 (Heltec WiFi Kit 32), chip esp32
Date: 2026-07-14 (documentation backfill - findings from an earlier audit pass, not new research)

Sources consulted:
- Vendor pins_arduino.h for this board (OLED display and Vext power-gate
  pin definitions; LED_BUILTIN/KEY_BUILTIN aliases).
- Heltec community forum: "WiFi Kit 32 PRG Button 0" - confirms GPIO0 is the
  onboard PRG button.
- espboards.dev pinout table - shows GPIO0 as KEY_BUILTIN (button, pulled up,
  press = LOW) and GPIO25 as LED_BUILTIN.
- Heltec official pinout diagram/schematic - confirms GPIO25 as onboard LED,
  active-high.
- Example sketches (referenced generically) using digitalWrite(25, HIGH) to
  turn the LED on - corroborates active-high polarity for GPIO25.

Per-pin findings:
- GPIO0: tagged ["digital_input", "button"]. Confirmed onboard PRG button
  (Heltec community forum "WiFi Kit 32 PRG Button 0"; espboards.dev pinout
  table shows GPIO0 as KEY_BUILTIN); pulled up, press = LOW.
- GPIO1, 2, 3, 5, 12, 13, 14, 18, 19, 22, 23, 26, 27, 32, 33, 34, 35, 36, 37,
  38, 39: left at the plain chip-level default capability set (no
  board-specific note).
- GPIO4, 15, 16: excluded (removed from chipGpios entirely) - dedicated
  onboard OLED display pins, per vendor pins_arduino.h.
- GPIO21: excluded (removed from chipGpios entirely) - dedicated onboard
  Vext power-gate pin, per vendor pins_arduino.h.
- GPIO25: tagged ["digital_output", "pwm_output", "led_high"]. Confirmed
  onboard LED, active-high (Heltec official pinout diagram/schematic and
  espboards.dev pinout table show GPIO25 as LED_BUILTIN; example sketches
  use digitalWrite(25, HIGH) to turn it on).

Summary: GPIO0 tagged button (onboard PRG button) and GPIO25 tagged led_high
(onboard LED), both confirmed via Heltec community/vendor sources; GPIO4/15/16
excluded as dedicated OLED display pins and GPIO21 excluded as the Vext
power-gate pin.
