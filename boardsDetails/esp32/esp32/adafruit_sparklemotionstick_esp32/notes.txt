Board: adafruit_sparklemotionstick_esp32 (Adafruit Sparkle Motion Stick / ESP32)
Date: 2026-07-14 (documentation backfill - findings from an earlier audit pass, not new research)

Sources consulted:
- https://learn.adafruit.com/adafruit-sparkle-motion-stick/pinouts -
  cited directly in the board.json comment: confirms GPIO4 is "labeled 4
  on the board" (red status LED) and GPIO18 is "labeled Neo on the board"
  (addressable NeoPixel).
- Adafruit's own per-board Blink guide convention (digitalWrite HIGH
  turns the LED on) - cited as the basis for GPIO4's active-high polarity.
- This board's own vendor pins_arduino.h - cited for PIN_NEOPIXEL=18
  (matching GPIO18's tag) and for TX=25/RX=26/SDA=13/SCL=15/SS=19/
  MISO=23/A0=2 alias checks (confirming no collision with GPIO0/4/18).
- Vendor-documented statement that the onboard boot button "can be read
  as an input in code", cited as confirming GPIO0 is not purely a
  bootloader-entry pin.

Per-pin findings:
- GPIO0: tagged ["digital_input", "button"] - confirmed onboard boot
  button, vendor-documented as user-readable in code (not purely a
  bootloader-entry pin). No TX/RX/SDA/SCL/SPI alias collision found.
- GPIO4: tagged ["digital_output", "led_high", "pwm_output"] - confirmed
  onboard red status LED (Adafruit pinouts page: "labeled 4 on the
  board"), active-high per Adafruit's per-board Blink guide convention.
- GPIO18: tagged ["digital_output", "led_neopixel", "pwm_output"] -
  confirmed onboard addressable RGB NeoPixel (same pinouts page: "labeled
  Neo on the board"), matching this board's own pins_arduino.h
  PIN_NEOPIXEL=18.
- GPIO21, GPIO22: excluded (capabilities: [] / omitted from chipGpios) -
  dedicated onboard DotStar LED output (MOSI/SCK, per vendor "output to
  drive dotstars" comment).
- All other listed GPIOs (1, 2, 3, 5, 12, 13, 14, 15, 19, 23, 25, 26, 27,
  32, 33, 34, 35, 36, 37, 38, 39): kept, unchanged generic capabilities.

Summary: GPIO21/22 excluded as dedicated onboard DotStar LED output;
GPIO4 tagged led_high (confirmed active-high onboard red status LED);
GPIO18 tagged led_neopixel (confirmed onboard addressable NeoPixel);
GPIO0 tagged button (confirmed onboard boot button, user-readable in
code) - all per Adafruit's own pinouts documentation and this board's
vendor pins_arduino.h.
