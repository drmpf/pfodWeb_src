Board: bpi-bit (Banana Pi BPI-Bit / ESP32)
Date: 2026-07-14 (documentation backfill - findings from an earlier audit pass, not new research)

Sources consulted:
- Banana Pi BPI-Bit wiki/docs - cited directly in the board.json comment
  as confirming 25 WS2812 addressable RGB LEDs (5x5 matrix) driven from a
  single data GPIO, and as confirming onboard Button A (GPIO35) and
  Button B (GPIO27) pushbuttons.
- Vendor pins_arduino.h - cited as the source identifying GPIO0 as the
  dedicated onboard MPU9250 IMU interrupt line.

Per-pin findings:
- GPIO0: excluded (capabilities: [] / omitted from chipGpios) - dedicated
  onboard MPU9250 IMU interrupt line, not general-purpose.
- GPIO4: tagged ["digital_output", "led_neopixel", "pwm_output"] -
  confirmed 25 WS2812 addressable RGB LEDs (5x5 matrix) driven from this
  single data GPIO (Banana Pi BPI-Bit wiki/docs).
- GPIO27: tagged ["digital_input", "button"] - confirmed onboard Button B
  pushbutton (Banana Pi BPI-Bit wiki/docs).
- GPIO35: tagged ["digital_input", "button"] - confirmed onboard Button A
  pushbutton (Banana Pi BPI-Bit wiki/docs).
- All other listed GPIOs (1, 2, 3, 5, 12, 13, 14, 15, 18, 19, 21, 22, 23,
  25, 26, 32, 33, 34, 36, 37, 38, 39): kept, unchanged generic
  capabilities.

Summary: GPIO0 excluded as a dedicated onboard MPU9250 IMU interrupt
line; GPIO4 tagged led_neopixel (confirmed 25-LED WS2812 5x5 matrix);
GPIO35/GPIO27 tagged button (confirmed onboard Button A/Button B) - all
per the Banana Pi BPI-Bit wiki/docs and vendor pins_arduino.h.
