- GPIO1, 2, 3, 12, 13, 22, 23, 34, 35, 36, 37, 38, 39: left at the plain
  chip-level default capability set (no board-specific note).
- GPIO4, 15, 16: excluded (removed from chipGpios entirely) - dedicated
  onboard OLED I2C+reset pins, per vendor pins_arduino.h.
- GPIO5, 18, 19, 27: excluded (removed from chipGpios entirely) - dedicated
  onboard LoRa SPI bus pins, per vendor pins_arduino.h.
- GPIO14, 26, 32, 33: excluded (removed from chipGpios entirely) - dedicated
  onboard LoRa RST/DIO0-2 pins, per vendor pins_arduino.h.
- GPIO21: excluded (removed from chipGpios entirely) - dedicated onboard
  Vext power-gate pin, per vendor pins_arduino.h.
- GPIO25: tagged ["digital_output", "led_high", "pwm_output"]. Confirmed
  onboard single-color LED (LED0, GPIO25, high active) per RIOT-OS board
  support docs; matches LED_BUILTIN/LED/DAC1/A18 aliases in vendor
  pins_arduino.h.

Summary: GPIO0 tagged button and GPIO25 tagged led_high, both confirmed via
RIOT-OS board-specific support docs and Heltec community forum; GPIO4/15/16
(OLED), GPIO5/18/19/27 (LoRa SPI), GPIO14/26/32/33 (LoRa RST/DIO0-2), and
GPIO21 (Vext power-gate) all excluded as dedicated onboard hardware pins.
