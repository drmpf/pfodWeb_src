Board: cnrs_aw2eth (AW2ETH / ESP32)
Date: 2026-07-14 (documentation backfill - findings from an earlier audit pass, not new research)

Sources consulted:
- Vendor/PR research confirming the AW2ETH board's hardware: LAN8720A
  Ethernet PHY + Micro SD on SPI + TCA9548A I2C switch + EEPROM (cited
  directly in the board.json top-of-file comment).
- This board's own vendor pins_arduino.h - cited as exposing GPIO0/25/26/
  27 as regular analog/touch aliases, which contradicts the standard
  ESP32 EMAC RMII pinout assumption.

Per-pin findings:
- GPIO4, GPIO5, GPIO13, GPIO14: excluded (capabilities: [] / omitted from
  chipGpios) - dedicated onboard microSD card SPI bus (AW2ETH board
  confirmed via vendor/PR research: LAN8720A Ethernet PHY + Micro SD on
  SPI + TCA9548A I2C switch + EEPROM).
- Ethernet RMII pins: explicitly NOT excluded. The board.json comment
  notes this board's own pins_arduino.h exposes GPIO0/25/26/27 as regular
  analog/touch aliases, contradicting the standard ESP32 EMAC RMII pinout
  assumption, so the exact RMII pin set could not be confirmed without a
  schematic - left as-is rather than guessed.
- GPIO0, GPIO1, GPIO2, GPIO3, GPIO12, GPIO15, GPIO18, GPIO19, GPIO21,
  GPIO22, GPIO23, GPIO25, GPIO26, GPIO27, GPIO32, GPIO33, GPIO34, GPIO35,
  GPIO36, GPIO37, GPIO38, GPIO39: kept, unchanged generic capabilities (no
  button/LED findings recorded for this board).

Summary: GPIO4/5/13/14 excluded as the dedicated onboard microSD SPI bus,
confirmed via vendor/PR research into the AW2ETH board's hardware
(LAN8720A PHY + microSD/SPI + TCA9548A I2C switch + EEPROM). Ethernet
RMII pins were deliberately left untouched because this board's
pins_arduino.h contradicts the standard RMII pinout assumption and no
schematic was available to confirm the real pin set - documented as an
open item rather than guessed.
