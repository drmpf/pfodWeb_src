Board: adafruit_feather_esp32_v2 (Adafruit HUZZAH32 Feather V2 / ESP32)
Date: 2026-07-14 (independent verification pass - real external research,
replacing the earlier pass's reliance on this repo's own vendor

Sources consulted (real, external, independently checked):
- https://learn.adafruit.com/adafruit-esp32-feather-v2/pinouts - Adafruit's
  own official Learn guide pinouts page for this exact board. Confirms:
  - GPIO2 (NEOPIXEL_I2C_POWER): "a power pin that must be pulled high" to
    enable both the onboard NeoPixel RGB LED and the STEMMA QT connector's
    power supply - specifically "the separate 3.3V regulator that powers
    the QT connector's red wire"; pulling it LOW disables that regulator
    for low-power operation.
  - GPIO13 (LED_BUILTIN / red LED): "set high to turn on", labelled "#13"
    on the silk, "a little red LED" controllable like any LED.
  - GPIO38 (BUTTON): "a user readable button switch to use as an input,
    labeled SW38 on the silk" - "an input-only pin" with "a pull-up on
    board".
- https://learn.adafruit.com/adafruit-esp32-feather-v2/neopixel-led -
  Adafruit's dedicated NeoPixel page for this board, corroborating the
  GPIO2 power-gate behaviour.
- This board's own vendor pins_arduino.h (variants/esp32/esp32/
  adafruit_feather_esp32_v2/pins_arduino.h), cross-checked against the
  above for consistency (matches: `#define BUTTON 38`, `LED_BUILTIN = 13`,
  NEOPIXEL_I2C_POWER commented out on GPIO2 with the same rationale).

Per-pin findings:
- GPIO2: excluded (capabilities: [] / omitted from chipGpios) - internal
  power-gate for the onboard NeoPixel + STEMMA QT I2C connector, not
  general-purpose. CONFIRMED via Adafruit's own Learn guide (see above) -
  this is a real, independently-verified vendor source, not just the
  repo's own copied pins_arduino.h comment.
- GPIO13: tagged ["digital_output", "pwm_output", "led_high"] - confirmed
  active-high user LED. CONFIRMED via Adafruit's own Learn guide pinouts
  page ("set high to turn on").
- GPIO38: tagged ["digital_input", "button"] - confirmed onboard button
  switch (silkscreened "SW38"), input-only with an onboard pull-up.
  CONFIRMED via Adafruit's own Learn guide pinouts page.
- All other listed GPIOs (0, 1, 3, 4, 5, 12, 14, 15, 18, 19, 21, 22, 23,
  25, 26, 27, 32, 33, 34, 35, 36, 37, 39): kept, unchanged generic
  capabilities - nothing in Adafruit's documentation suggests any of
