SOURCES CONSULTED
------------------
1. https://raw.githubusercontent.com/Xinyuan-LilyGO/LilyGo-LoRa-Series/master/schematic/T3_V1.6.1.pdf
   Official LilyGO schematic (repo Xinyuan-LilyGO/LilyGo-LoRa-Series, sheet "TTGO LORA T3_V1.6", dated 2021-01-06).
   Successfully fetched and read as a real 4-page PDF (verified via `file` = "PDF document, version 1.3, 4 pages").
   Sheet 1 "LED" block shows two LEDs: a RED LED wired through a resistor to VBUS (hardware USB-power-present
   indicator, not GPIO-controlled) and a GREEN LED wired through a resistor to net "IO25" (i.e. GPIO25) -
   this is the software-controllable status LED. No pushbutton/switch symbol is wired to the IO0 net anywhere
   on the schematic. The only physical switches shown are: SW3 "reset" (wired to RST/EN net = hardware reset
   button) on sheet 1, and JP1 "SK-12D02" (a slide switch in the VBAT/power path) on sheet 4 - a power
   ON/OFF switch, not a GPIO button. GPIO0 only appears wired to the CP2104 USB-UART bridge's auto-program
   transistor circuit (U3/UMH3N, driven by DTR/RTS) for automatic bootloader entry during flashing - there is
   no manual pushbutton on this net.

2. https://raw.githubusercontent.com/zephyrproject-rtos/zephyr/main/boards/lilygo/ttgo_lora32/ttgo_lora32_esp32_procpu.dts

   boards that have one (as most ESP32 devkits do), did not add one for this board - independent
   corroboration that there is no wired user button.

PINS CONSIDERED BUT NOT TAGGED
-------------------------------
- GPIO0 (pins_arduino.h KEY_BUILTIN alias, suggesting a "key"/button): investigated specifically because the
  task warns alias names are often wrong. The official LilyGO schematic (source 1) was checked directly and
  shows NO pushbutton, switch, or key component wired to the IO0 net - only the CP2104 USB-UART auto-program
  transistor circuit (used only during firmware flashing, not user-operable) and the ESP32-SIP pin itself.
  The only two physical user-operable switches on the whole board are a RESET button (wired to RST/EN, not a
  general GPIO) and a power slide switch (in the battery/VBUS path, not wired to any GPIO at all). This is
  corroborated by Zephyr's upstream board port having no button/gpio-keys node, and by LilyGO's own product
  page listing only "Reset \ Power switch" as onboard functions. This is a definite (not a guess) finding:
  GPIO0 is NOT a confirmable user button on this specific board revision, so it was deliberately left
  untagged. No capability change was made to GPIO0.
- GPIO25 RED LED path: the schematic (source 1) shows a second, RED LED on this board's LED block, but it is
  wired directly to VBUS (hardware USB-power-presence indicator), not to any GPIO - so there is no GPIO to
  tag for it. Not tagged because it is not GPIO-controlled at all, not because of any uncertainty.
