Board: ESP32-S3 Dev Module (generic esp32s3 chip-bucket board;
variants/esp32/esp32s3/esp32s3/board.json)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- Espressif ESP-IDF documentation (docs.espressif.com) - basis for the
  chipGpios capability map itself (GPIOs 26-32 flash, 33-37 octal
  flash/PSRAM, and 19-20 USB excluded; GPIOs 22-25 do not exist in this
  chip's silicon; no DAC on this chip). Also basis for the ESP32-S3
  Technical Reference Manual "Strapping Pins" cited in pinNotes
  (GPIO0/3/45/46).
- pins_arduino.h (vendor, ESP32-S3-DevKitC-1 v1.0-based) - basis for the
  "pfodWeb capability retrofit" note: PIN_RGB_LED 48 / RGB_BUILTIN defines
  GPIO48 as the onboard NeoPixel (WS2812) RGB LED, matching the
  ESP32-S3-DevKitC-1 v1.0 board this generic variant is based on.

Per-pin findings:
- GPIO0: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag (pinNotes: "Must be HIGH for normal boot").
- GPIO1-GPIO10: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO11-GPIO18: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO21, GPIO38-GPIO45, GPIO47: capabilities [digital_input,
  digital_output, pwm_output] - generic, no tag. (pinNotes: GPIO3/45/46
  "Must be LOW or floating on reboot".)
- GPIO46: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO48: capabilities [digital_output, pwm_output, led_neopixel] - tagged
  "led_neopixel". Confirmed onboard NeoPixel (WS2812) RGB LED — vendor
  pins_arduino.h defines PIN_RGB_LED 48 / RGB_BUILTIN, matching the
  ESP32-S3-DevKitC-1 v1.0 board this generic variant is based on.

Summary: This is a per-board board.json for the generic "esp32s3" board id
(distinct from the plain chip-level default at
variants/esp32/esp32s3/board.json, which has no led_neopixel tag). All 31
chipGpios entries carry the standard Espressif ESP-IDF chip capability set
except GPIO48, tagged "led_neopixel" for the onboard NeoPixel RGB LED
matching the ESP32-S3-DevKitC-1 v1.0 reference board.
