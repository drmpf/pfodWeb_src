Pins considered but NOT tagged:

  button, not a general-purpose user button, and per this board's own board.json it is
  already excluded from chipGpios as the dedicated ST7262 LCD "G3" RGB data line
  (WS_LCD_G3 = GPIO0 in pins_arduino.h). Re-adding/tagging it would reverse an existing,
  deliberate pin-exclusion, which is out of scope for this task. No guess made - this is
  a clear "leave alone" case, not a judgment call.
- PWR/CHG/DONE status indicators: confirmed by vendor docs to be driven by the CS8501
  battery charge-management chip, independent of any ESP32 GPIO. There is no GPIO to
  tag for these at all - they are not MCU-controllable outputs. No judgment call needed;
  this is definitively out of scope for GPIO capability tagging.
