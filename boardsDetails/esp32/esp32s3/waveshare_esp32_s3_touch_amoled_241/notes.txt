PINS CONSIDERED BUT NOT TAGGED
-------------------------------
- No onboard LED (single-color or NeoPixel/RGB) is documented anywhere for this
  board across all sources checked. No LED-related GPIO was found in the wiki
  page, product page snippets, or pins_arduino.h (no LED_BUILTIN-style define
  exists in this board's pins_arduino.h at all). Decision: made NO guess -
  did not tag any LED capability.
- RESET button: this is a hardware EN/reset line, not a GPIO the sketch can read
  as a digital input, so it is not a "button" candidate in the pfodWeb
  digital_input/button sense. Not tagged (not applicable, not a judgment call).
- PWR button: per the wiki text this is a physical switch for controlling
  lithium-battery power delivery, not a GPIO-readable user button. Not tagged
  (not applicable, not a judgment call).
- GPIO16/17 (BAT_Control / BAT_ADC) and GPIO15 (Key_BAT): battery-monitoring
  circuit pins, not button/LED candidates. Not tagged.
- Checked GPIO0 against this board's TX/RX (TX=43, RX=44 per pins_arduino.h) -
  no conflict, so the button tag was safe to apply.
