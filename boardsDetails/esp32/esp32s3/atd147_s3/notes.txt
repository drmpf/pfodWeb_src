Board: atd147_s3 (ArtronShop ATD1.47-S3), chip esp32s3
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- Vendor pins_arduino.h for this board (cited generically for the TFT SPI
  bus/reset and display-DC exclusions)
- ArtronShop/ATD1.47-S3-Lib GitHub repository, src/Switch.cpp:
  switch_pin[] = {4, 5, 45}, pinMode(INPUT_PULLUP), digitalRead debounced
  switch A/B/C (confirms the three onboard buttons and their GPIOs)

Per-pin findings:
- GPIO10,11,12,13,14: excluded entirely from chipGpios - dedicated onboard
  TFT display SPI bus + reset (per vendor pins_arduino.h).
- GPIO21: excluded entirely from chipGpios - dedicated onboard TFT display
  DC line (per vendor pins_arduino.h).
- GPIO4: tagged "button" (BTN_A/KEY_BUILTIN) - confirmed via
  ArtronShop/ATD1.47-S3-Lib src/Switch.cpp: switch_pin[] = {4,5,45},
  pinMode(INPUT_PULLUP), digitalRead debounced switch A. Capabilities:
  ["digital_input", "button"] (analog_input dropped).
- GPIO5: tagged "button" (BTN_B) - same source, switch B. Capabilities:
  ["digital_input", "button"].
- GPIO45: tagged "button" (BTN_C) - same source, switch C. Capabilities:
  ["digital_input", "button"].
- GPIO0,1,2,3,6,7,8,9: no tag - standard capabilities ["analog_input",
  "digital_input", "digital_output", "pwm_output"] (GPIO0 kept as
  ["digital_input", "digital_output", "pwm_output"] without analog_input
  in the source board.json).
- GPIO15,16,17,18: no tag - standard ADC2-range capabilities
  ["analog_input_serial", "digital_input", "digital_output", "pwm_output"].
- GPIO38,39,40,41,42,43,44,46,47,48: no tag - standard capabilities
  ["digital_input", "digital_output", "pwm_output"].
- No LEDs were identified or tagged on this board.

Summary: GPIO10-14/21 excluded (dedicated onboard TFT display bus/DC);
GPIO4/5/45 tagged button (BTN_A/BTN_B/BTN_C, confirmed via ArtronShop's own
ATD1.47-S3-Lib firmware source); no LEDs found.
