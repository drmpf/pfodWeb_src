Board: Cytron Maker Feather AIoT S3 (ESP32-S3 Dev Module variant)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- espboards.dev pinout table - basis for GPIO0 "BOOT 0" Boot Button and GPIO3
  "BUTTON 3" User Button.
- pins_arduino.h (vendor) - corroborates "BOOT 0" Boot Button and "BUTTON 3"
  User Button aliases.
- CNX Software / Adafruit blog - corroborates "built-in RGB LED wired to D46".

Per-pin findings:
- GPIO0: capabilities [digital_input, button] - tagged "button". Confirmed
  BOOT button (espboards.dev pinout table; matches pins_arduino.h "BOOT 0"
  Boot Button).
- GPIO1, GPIO2: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO3: capabilities [digital_input, button] - tagged "button". Confirmed
  User Button (espboards.dev pinout table; matches pins_arduino.h "BUTTON 3"
  User Button).
- GPIO4-GPIO10: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO11: excluded (no chipGpios entry) - internal peripheral-power-enable
  line (VP_EN), not general-purpose.
- GPIO12-GPIO18: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO21, GPIO38-GPIO45: capabilities [digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO46: capabilities [digital_output, pwm_output, led_neopixel] - tagged
  "led_neopixel". Confirmed onboard RGB NeoPixel data pin (espboards.dev
  pinout; CNX Software/Adafruit blog: "built-in RGB LED wired to D46").
- GPIO47, GPIO48: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.

Summary: GPIO0 tagged as BOOT button, GPIO3 tagged as User Button, GPIO46
tagged as the onboard NeoPixel RGB LED (all confirmed via espboards.dev
pinout table and vendor pins_arduino.h aliases), and GPIO11 excluded as the
internal VP_EN peripheral-power-enable line.
