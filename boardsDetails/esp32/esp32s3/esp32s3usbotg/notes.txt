Board: Espressif ESP32-S3-USB-OTG (ESP32-S3 Dev Module variant)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- Espressif ESP32-S3-USB-OTG user guide - confirmed GPIO0 BUTTON_OK
  (active-low), GPIO10 BUTTON_UP (active-low), GPIO11 BUTTON_DOWN
  (active-low), GPIO14 BUTTON_MENU (active-low), GPIO15 LED_GREEN
  (active-high), GPIO16 LED_YELLOW (active-high).
- board.json's own top-of-file comment (no further external URLs) - basis
  for excluding the onboard microSD card (SDMMC/SPI), 240x240 ST7789 LCD,
  and USB dual-role power/mode control lines, and for keeping the JTAG
  header pins as plain GPIO when not actively debugging.

Per-pin findings:
- GPIO0: capabilities [digital_input, button] - tagged "button". Confirmed
  BUTTON_OK, active-low, per Espressif ESP32-S3-USB-OTG user guide.
- GPIO1, GPIO2, GPIO3: capabilities [analog_input, digital_input,
  digital_output, pwm_output] - kept as voltage monitors, no tag.
- GPIO4, GPIO5, GPIO6, GPIO7, GPIO8, GPIO9: excluded (removed from
  chipGpios entirely) - onboard 240x240 ST7789 LCD (DC/CS/CLK/MOSI/RST/BL).
- GPIO10: capabilities [digital_input, button] - tagged "button". Confirmed
  BUTTON_UP, active-low, per Espressif ESP32-S3-USB-OTG user guide.
- GPIO11: capabilities [digital_input, button] - tagged "button". Confirmed
  BUTTON_DOWN, active-low, per Espressif ESP32-S3-USB-OTG user guide.
- GPIO12, GPIO13, GPIO17, GPIO18: excluded (removed from chipGpios
  entirely) - USB dual-role power/mode control lines (DEV_VBUS_EN/
  BOOST_EN/LIMIT_EN/USB_HOST_EN).
- GPIO14: capabilities [digital_input, button] - tagged "button". Confirmed
  BUTTON_MENU, active-low, per Espressif ESP32-S3-USB-OTG user guide.
- GPIO15: capabilities [digital_output, led_high, pwm_output] - tagged
  "led_high". Confirmed LED_GREEN, active-high, per Espressif
  ESP32-S3-USB-OTG user guide.
- GPIO16: capabilities [digital_output, led_high, pwm_output] - tagged
  "led_high". Confirmed LED_YELLOW, active-high, per Espressif
  ESP32-S3-USB-OTG user guide.
- GPIO21: kept as overcurrent flag. Capabilities [digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO33, GPIO34, GPIO35, GPIO36, GPIO37, GPIO38: excluded (removed from
  chipGpios entirely) - onboard microSD card (SDMMC/SPI). (GPIO33-37 are
  also part of the octal flash/PSRAM range already excluded chip-wide.)
- GPIO39, GPIO40, GPIO41, GPIO42: kept as JTAG header pins, usable as plain
  GPIO when not actively debugging. Capabilities [digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO43, GPIO44, GPIO45, GPIO46, GPIO47, GPIO48: capabilities
  [digital_input, digital_output, pwm_output] - generic, no tag.

Summary: Tagged GPIO0/10/11/14 as "button" (BUTTON_OK/UP/DOWN/MENU) and
GPIO15/16 as "led_high" (LED_GREEN/LED_YELLOW), all confirmed per the
Espressif ESP32-S3-USB-OTG user guide; excluded the onboard microSD card,
ST7789 LCD, and USB dual-role control lines as dedicated hardware; kept
voltage monitors, the overcurrent flag, and JTAG header pins as plain GPIO.
