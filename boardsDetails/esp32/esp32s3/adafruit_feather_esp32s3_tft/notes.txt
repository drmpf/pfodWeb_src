Board: Adafruit Feather ESP32-S3 TFT (ESP32-S3 Dev Module variant)
Date: 2026-07-14 (independent verification pass - real vendor/upstream sources
consulted, replacing the earlier documentation-backfill pass that only cited
the repo's own board.json comment)

Sources consulted (real, independently fetched):
1. Official pins_arduino.h, espressif/arduino-esp32 (the actual upstream
   Arduino core this board.json is derived from):
   https://github.com/espressif/arduino-esp32/blob/master/variants/adafruit_feather_esp32s3_tft/pins_arduino.h
   Relevant definitions:
     #define LED_BUILTIN 13
     #define PIN_NEOPIXEL 33
     #define NEOPIXEL_NUM 1
     #define NEOPIXEL_POWER 34
     #define NEOPIXEL_POWER_ON HIGH

2. Adafruit's own pinouts page (confirms LED and button):
   https://learn.adafruit.com/adafruit-esp32-s3-tft-feather/pinouts
   States: "Red LED: available in CircuitPython as board.LED, and in
   Arduino as LED_BUILTIN or 13"; "Boot button: Available as board.BUTTON
   in CircuitPython, Arduino pin 0".

Per-pin findings:
- GPIO0: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag. pinNotes: "Must be HIGH for normal boot" (standard
  strapping-pin note, not part of this audit). Note: Adafruit's own
  pinouts page names this the "Boot button" pin, but it is a BOOT0/DFU
  strapping-pin function shared with every ESP32-S3 board (used to enter
  the ROM bootloader when held during reset/power-up), not a
  general-purpose user pushbutton wired to a dedicated switch - consistent
  with how this repo treats BOOT0 pins elsewhere (tagged "button" only
  where the board explicitly documents a labelled onboard pushbutton
  wired for that purpose, as on the Metro ESP32-S3 below). Left as-is,
  no change.
- GPIO1-GPIO6: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO7: excluded (no chipGpios entry). CONFIRMED - this is TFT_CS (TFT
  chip-select / SPI SS), per the official pins_arduino.h above.
- GPIO8-GPIO10: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO11, GPIO12: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO13: capabilities [digital_output, pwm_output, led_high] - tagged
  "led_high". CONFIRMED - LED_BUILTIN=13 in the official pins_arduino.h;
  active-high polarity confirmed by Adafruit's own pinouts page (source 2
  above), which documents the same circuit as the other Feather
  ESP32-Sx boards.
- GPIO14-GPIO18: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO21: excluded (no chipGpios entry). CONFIRMED - this is
  TFT_I2C_POWER (power-gate for the TFT display, battery monitor, and
  STEMMA QT connector), per the official pins_arduino.h above.
- GPIO34: excluded (no chipGpios entry). CONFIRMED - this is
  NEOPIXEL_POWER (power-gate for the onboard NeoPixel), per the official
  pins_arduino.h above.
- GPIO35-GPIO37, GPIO39, GPIO40, GPIO45: excluded (no chipGpios entries).
  CONFIRMED - these are exactly the TFT SPI bus and control pins per the
  official pins_arduino.h: MOSI=35, SCK=36, MISO=37, TFT_DC=39, TFT_RST=40,
  TFT_BACKLITE=45. Matches the claimed "GPIO35-37/39/40/45" range
  pin-for-pin (TFT_CS=7 is separately excluded above).
- GPIO38: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO41-GPIO44: capabilities [digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO46-GPIO48: capabilities [digital_input, digital_output,
  pwm_output] - generic, no tag. pinNotes on GPIO3/45/46: "Must be LOW or
  floating on reboot" (standard strapping-pin notes; GPIO45 is also
  excluded above as part of the TFT bus).
- GPIO33 (PIN_NEOPIXEL per pins_arduino.h): NOT tagged and not present as
  a chipGpios entry. CONFIRMED this is correctly left untagged - GPIO33 is
  outside the pin range this board.json variant exposes.

Summary: Every existing finding was independently confirmed against the
official, actively-maintained espressif/arduino-esp32 pins_arduino.h for
this exact board variant, plus Adafruit's own pinouts page. GPIO13 =
confirmed active-high onboard user LED. GPIO7/35-37/39/40/45 = confirmed
dedicated onboard TFT display + SPI bus. GPIO21/34 = confirmed internal
power-gate lines (TFT_I2C_POWER/NEOPIXEL_POWER). No corrections were
required - all prior findings hold up under real independent
verification.
