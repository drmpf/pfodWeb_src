https://files.waveshare.com/wiki/ESP32-S3-Touch-LCD-4.3/ESP32-S3-Touch-LCD-4.3-Sch.pdf
  ***Authoritative source*** - the actual vendor schematic PDF for THIS exact
  board (4.3, not 4.3B). Downloaded and text-extracted with pdftotext (WebFetch
  could not parse the binary PDF itself). Findings from the extracted text:
    - Two push-button switches present, both labelled "KEY" in the schematic:
        * K1 KEY -> pull-up resistor R38 10K -> net labelled "RESET".
          The ESP32-S3-WROOM-1/2 module pin table (module pin 3) shows this
          "RESET" net is actually the module's EN (chip-enable) pin, not a
          GPIO - i.e. this is a hardware reset button, has no GPIO number,
          and cannot be represented as a chipGpios digital_input at all.
        * K2 KEY -> pull-up resistor R39 10K + debounce cap C38 100nF ->
          net labelled "IO0". The module pin table explicitly cross-references
          module pin 27 "IO0" to the LCD signal "G3" (i.e. GPIO0 = LCD
          signal G3), matching this board's own pins_arduino.h
          (#define WS_LCD_G3 0) and matching the pre-existing board.json
          NOTE that GPIO0 was already removed
          from chipGpios as a dedicated onboard LCD RGB data line. So the
          BOOT button (K2) shares GPIO0 with the LCD's G3 data line.
    - Searched extracted schematic text for "LED", "PWR", "CHG", "DONE",
      "WS2812", "NeoPixel": found only "Led1"/"Led2" (two red LEDs) wired
      into the battery-charging section next to charge-IC U4 (pins
      CHRG/STDBY/PROG/BAT, part of the CS8501 charge-management circuit).
      No net connecting Led1/Led2 to any ESP32 GPIO was found - they are
      driven directly by the charging IC's own status pins (hardware-only
      PWR/CHG/DONE indicators, matching the vendor doc page description).
      No WS2812/NeoPixel component or net found anywhere in the schematic.
