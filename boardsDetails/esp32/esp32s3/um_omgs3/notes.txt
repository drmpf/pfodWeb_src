Board: Unexpected Maker OMGS3 (chip: esp32s3)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Note: This board has NO dedicated board.json of its own — only a
pins_arduino.h exists at variants/esp32/esp32s3/um_omgs3/. It relies on
build_boards.js's ancestor-fallback mechanism and shares the plain
chip-level default at variants/esp32/esp32s3/board.json (31 chipGpios
entries). No vendor-specific button/LED pins were found or tagged for this
board specifically — this is an honest statement that no per-board audit
was performed for um_omgs3, not a finding that it has no onboard
button/LED hardware.

Sources consulted (from the shared chip-level default board.json's own
comments):
- Espressif ESP-IDF documentation (docs.espressif.com) - basis for the
  chipGpios capability map (GPIOs 26-32 flash, 33-37 octal flash/PSRAM, and
  19-20 USB excluded; GPIOs 22-25 do not exist in this chip's silicon; no
  DAC on this chip).
- ESP32-S3 Technical Reference Manual - Strapping Pins - basis for the
  pinNotes on GPIO0/3/45/46.

Per-pin findings:
- GPIO0: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag (pinNotes: "Must be HIGH for normal boot").
- GPIO1-GPIO10: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO11-GPIO18: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO21, GPIO38-GPIO48: capabilities [digital_input, digital_output,
  pwm_output] - generic, no tag. (pinNotes: GPIO3/45/46 "Must be LOW or
  floating on reboot".)
- Note: unlike the per-board variants/esp32/esp32s3/esp32s3/board.json
  (which tags GPIO48 as "led_neopixel" for the ESP32-S3-DevKitC-1 v1.0
  reference board), the plain chip-level default shared by um_omgs3 leaves
  GPIO48 untagged (plain digital_output/pwm_output) since it carries no
  board-specific assumptions.

Summary: um_omgs3 has no dedicated board.json and inherits the plain
esp32s3 chip-level default (31 GPIO entries, no button/LED tags) via
build_boards.js's ancestor-fallback mechanism. No board-specific pin audit
has been performed for this board.
