TAGGED
------
GPIO0 -> ["digital_input", "button"] - confirmed onboard BOOT button via the
vendor's own product photo callout ("Boot button") and pinout table (GP0 labelled
"Boot"). Not TX/RX (TX=43, RX=44), so the tag is not silently discarded by
build_boards.js's TX/RX hard-reservation. Previous capabilities on GPIO0
(digital_output, pwm_output) were stripped per the button-tag policy.

CONSIDERED BUT NOT TAGGED
--------------------------
- Reset button (silkscreen "RST", tied to the EN/chip-enable line): this is not
  a GPIO at all (EN is the 3.3V regulator/chip-reset enable pin, not part of
  chipGpios), so there is no GPIO to tag - not a judgment call, simply not
  applicable to this task's tagging mechanism.
- "Charge indicator" LED (next to the USB-C port, per the resource photo): this
  is a hardware battery-charge-status LED driven directly by the onboard charge-
  management IC's own status pin, not by an ESP32-S3 GPIO the user's sketch can
  control - not tagged. No guess was made; this is based on the resource photo's
  own labeling and typical charge-IC LED wiring (no charge-LED GPIO number is
  given anywhere in the vendor material, consistent with it not being GPIO-driven).
- No RGB/NeoPixel LED of any kind was found anywhere in the vendor material for
  this specific board - none exists on this board (unlike some other Waveshare
  dev boards that do have one).
- GPIO16 (TE, "NC by default") and GPIO41 (TP_INT) appear in this board's
  chipGpios with full general-purpose capabilities despite the vendor's touch
  pinout table listing them as display/touch-related. This is a pin-EXCLUSION
  question (already-audited scope), not a button/LED question, so no change was
  made here - flagging only as a note for a human reviewer doing a future
  pin-exclusion re-audit pass on this board, not acted on in this task.

SUMMARY
-------
Tagged GPIO0 as the confirmed onboard BOOT button (["digital_input","button"]).
No onboard user-controllable LED exists on this board (only a non-GPIO charge
indicator) - no LED tag applied.
