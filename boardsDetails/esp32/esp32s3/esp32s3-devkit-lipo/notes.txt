Board: OLIMEX ESP32-S3-DevKit-LiPo (ESP32-S3 Dev Module variant)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- OLIMEX ESP32-S3-DevKit-LiPo Rev B schematic - confirmed GPIO0\BUT1 ->
  R15 100R -> BUT1 -> GND (USER button, GPIO0 tagged "button"); confirmed
  +3.3V -> R13 2.2k -> anode, cathode -> GPIO38\LED1 (green USER LED,
  GPIO38 tagged "led_low" since the LED lights when GPIO38 is driven LOW).

Per-pin findings:
- GPIO0: capabilities [digital_input, button] - tagged "button". Confirmed
  USER button per OLIMEX ESP32-S3-DevKit-LiPo Rev B schematic
  (GPIO0\BUT1 -> R15 100R -> BUT1 -> GND).
- GPIO1-GPIO10: capabilities [analog_input, digital_input, digital_output,
  pwm_output] - generic, no tag.
- GPIO11-GPIO18: capabilities [analog_input_serial, digital_input,
  digital_output, pwm_output] - generic, no tag.
- GPIO21: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO38: capabilities [digital_output, pwm_output, led_low] - tagged
  "led_low". Confirmed green USER LED per OLIMEX ESP32-S3-DevKit-LiPo Rev B
  schematic (+3.3V -> R13 2.2k -> anode, cathode -> GPIO38\LED1, so the
  LED lights when GPIO38 is driven LOW).
- GPIO39-GPIO48: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.

Summary: GPIO0 tagged as the USER button and GPIO38 tagged as the green
USER LED (active-low), both confirmed directly from the OLIMEX
ESP32-S3-DevKit-LiPo Rev B schematic. All other pins retain the plain
chip-level default capability set.
