PINS CONSIDERED AND NOT TAGGED
-------------------------------
- GPIO0 (BOOT button, by analogy with every sibling board in this family): even if
  a BOOT button is confirmed to exist on GPIO0 for this "B" revision, GPIO0 is
  ALREADY excluded from this board's chipGpios (used as WS_LCD_G3, the ST7262 LCD's
  green-3 data line — pins_arduino.h line 24, board.json header NOTE lines 1-15).
  Per task rules, pins inside an existing pin-exclusion must not be re-added even if
  a button function is confirmed on them. No guess made about GPIO number since no
  5B-specific source gave one anyway; left untagged and excluded exactly as before.
  No board.json edit made for this reason.
- EN/CHIP_PU (RESET button): hardware reset line, not a firmware-readable GPIO, not
  taggable as a "button" capability regardless. Not a chipGpios entry at all.
- CH422G I2C IO-expander pins (this board's own file/board.json notes confirm it uses
  a CH422G, shared with the touch controller, for TP_RST/LCD_BL/LCD_RST/SD_CS/USB_SEL
  etc., matching the non-B 5 model's EXIO0-5/OD0-1 pin table): these are behind an
  I2C expander chip, not native ESP32-S3 GPIOs, so there is no chipGpios entry to tag
  regardless of function, and none of them is described as a button or user LED.
- DONE/CHARGE/POWER LEDs: described (source 8, cross-board) as passive battery
  charge/power indicators wired to the onboard CS8501 charge-management chip, not to
  any ESP32-S3 GPIO. Not user-controllable, not tagged.
- No WS2812/NeoPixel/RGB LED found in any fetched documentation for this board or its
  documented "B"-revision siblings (cross-checked per this session's known
  hallucination risk on Waveshare sibling-board pages — the product title/specs never
  mention an RGB/NeoPixel LED, unlike e.g. waveshare_esp32_s3_lcd_147 which explicitly
  advertises "With Colorful RGB LED"). Nothing to tag.
- This board's own wiki page (www.waveshare.com/wiki/ESP32-S3-Touch-LCD-5B) is
  explicitly unpublished ("under urgent production") at the time of this audit, so
  no direct 5B-specific GPIO citation for BOOT/RESET/LEDs could be obtained; the
  conclusion above rests on consistent cross-board pattern evidence (sources 8/9)
  rather than a page dedicated to this exact revision. Flagging this explicitly so a
  human reviewer can re-check once Waveshare publishes the 5B wiki page.
