PINS CONSIDERED BUT NOT TAGGED
-------------------------------
- PWR button (EXIO6): Confirmed by the vendor wiki text (source 1) to be
  wired to an I2C GPIO-expander pin ("extended IO"), not a direct ESP32-S3
  GPIO. board.json chipGpios only covers direct chip GPIOs, so this pin is
  out of scope for this task by construction - not a judgment call, simply
  not tag-able here. No expander pin number was found in the available
  snippets to even record precisely.
- No onboard status LED / NeoPixel was found in any of the sources above.
  This is a no-guess conclusion, not a best-guess judgment call: multiple
  vendor-side sources (wiki text, product page attempt, full GitHub repo
  file tree) were checked and none mention a general-purpose LED on this
  board. (The AMOLED backlight and its AW9364 driver are display control
  hardware, excluded per task instructions.) Left untagged.
- Checked GPIO0 against this board's TX/RX reservation (TX=43, RX=44 per
  pins_arduino.h `static const uint8_t TX = 43;` / `RX = 44;`) - no
  conflict, GPIO0 is clear to tag.
