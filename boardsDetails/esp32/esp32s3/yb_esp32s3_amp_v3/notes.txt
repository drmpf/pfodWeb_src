board with ESP32-S3, microSD slot, 2x MAX98357A I2S PCM Class-D amplifiers,

Researched: 2026-07-12

SOURCES CONSULTED
-----------------
- https://github.com/yellobyte/YB-ESP32-S3-AMP
  Vendor (YelloByte) GitHub repo for the YB-ESP32-S3-AMP board. Confirms this
  is a general-audio dev board: ESP32-S3-WROOM-1-N8R2, microSD slot, 2 x
  MAX98357A 3W Class-D I2S amplifiers, CH334 USB hub + CH343 USB-UART bridge,
  "two status LEDs" and "lots of GPIO pins for free usage".

- https://github.com/yellobyte/YB-ESP32-S3-AMP/blob/main/Readme.md and raw
  https://raw.githubusercontent.com/yellobyte/YB-ESP32-S3-AMP/main/Readme.md
  README text (applies to the current/latest hardware revision sold today,
  functionally unchanged across revisions per vendor's own retired-versions
  folder naming): "One LED labeled 'P' is connected to the 3.3V rail to
  indicate board power and the other LED labeled 'IO47' is connected to
  GPIO47 which can be used as status LED." Also: "If solder bridge DAC_MUTE
  is closed [default open] this pin can be used for muting the two audio
  amplifiers: active when GPIO47 is HIGH or muted when GPIO47 is LOW."
  Buttons: "One is labeled 'R' and resets the ESP32-S3 (shorts EN pin to
  ground) and the other one is labeled 'B' and shorts GPIO0 to ground when
  pressed. The latter is sometimes needed to force the board into boot
  mode." Text alone did not state LED polarity (on vs off at HIGH) for
  normal (non-mute) GPIO47 use, so the version-specific schematic was
  consulted next (below) - this is the definitive source used for tagging.

  Listing confirms dedicated "YB-ESP32-S3-AMP_Rev3_schematic_1_2.jpg" and

- https://raw.githubusercontent.com/yellobyte/YB-ESP32-S3-AMP/main/doc/retired_board_versions_V2_%26_V3/YB-ESP32-S3-AMP_Rev3_schematic_1_2.jpg
  DEFINITIVE source, fetched and viewed directly as an image (title block
  confirms "TITLE: YB-ESP32-S3-AMP", "REV: 3.0", "Date: 02.12.2024"). Three
  clearly labeled sub-circuit blocks:
    * "Reset Button": EN pin, R8 10k pull-up to 3V3, switch (RST_S1) to GND,
      C5 220n. EN is not an ESP32-S3 GPIO - out of scope for chipGpios
      tagging.
    * "GPIO0 Button": GPIO0 -> R1 330R -> switch (BOOT_S1) -> GND. Standard
      active-low pushbutton wired directly to a strapping-pin GPIO, exactly
      matching this repo's established convention (see
      boardsDetails/esp32/esp32s3/yb_esp32s3_eth/notes.txt and
      yb_esp32s3_drv/notes.txt) for tagging a confirmed GPIO0 pushbutton as
      "button".
    * "Status LED (GPIO47)": GPIO47 -> LED (silkscreen "IO47", anode toward
      GPIO47) -> R7 1k5 -> GND. Anode-to-GPIO / cathode-to-GND topology
      means the LED is lit when GPIO47 is driven HIGH => active-high
      (led_high).

- https://raw.githubusercontent.com/yellobyte/YB-ESP32-S3-AMP/main/doc/retired_board_versions_V2_%26_V3/YB-ESP32-S3-AMP_Rev3_schematic_2_2.jpg

PINS CONSIDERED BUT NOT TAGGED
-------------------------------
- 'P' power-indicator LED: not a candidate - README states it is wired
  directly to the 3.3V rail as a fixed power-on indicator, not GPIO-driven.
- Reset button 'R'/RST_S1: not a candidate - schematic confirms it shorts
  EN (chip enable/reset) to GND, and EN is not a GPIO exposed in
  chipGpios/pins_arduino.h.
- No NeoPixel/addressable RGB LED found anywhere in the README or either
  schematic sheet - GPIO47 is a plain single-color LED, not RGB_BUILTIN/
  PIN_NEOPIXEL.
- No other button or LED hardware found on either schematic sheet.
- No judgment-call/best-guess tagging was needed this pass - both the
  GPIO0 button and the GPIO47 LED were confirmed directly via the Rev
  3.0-specific vendor schematic (not just README prose), which is the
  strongest tier of evidence available and specific to this exact board
  revision.

WHAT WAS TAGGED (board.json edited in place)
---------------------------------------------
- GPIO0: capabilities changed from ["digital_input","digital_output",
  "pwm_output"] to ["digital_input","button"] (confirmed onboard "GPIO0
  Button" - R1 330R to switch to GND, Rev3 schematic sheet 1/2).

  "pwm_output"] to ["digital_output","pwm_output","led_high"] (confirmed
  onboard "Status LED (GPIO47)" - LED + R7 1k5 to GND, anode toward GPIO47,
  active-high, Rev3 schematic sheet 1/2; pwm_output retained since it was
  already present on this pin before tagging, per repo convention).
- Two pfodWeb NOTE comments added at the top of board.json (after the
  existing dedicated-hardware-exclusion NOTE) documenting both tags and
  citing the Rev3-specific vendor schematic source.
- pins_arduino.h: no changes required (no SDA/SCL/SS/MOSI/MISO/SCK alias
  collision found on GPIO0 or GPIO47).

SUMMARY
-------
Vendor/product confirmed as YelloByte YB-ESP32-S3-AMP, hardware Rev 3.0.
Tagged GPIO0 as "button" (onboard BOOT pushbutton to GND) and GPIO47 as
"led_high" (onboard "IO47" active-high status LED, which doubles as the
MAX98357A DAC_MUTE control net on the same pin) - both confirmed via the
Rev3-specific vendor schematic (not the generic/latest-revision doc/
folder schematic, which is for a different hardware revision).
