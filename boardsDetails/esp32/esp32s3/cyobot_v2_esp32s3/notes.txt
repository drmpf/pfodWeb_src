Board: cyobot_v2_esp32s3 (CYOBot v2, ESP32-S3), chip esp32s3
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- Vendor pins_arduino.h for this board (cited generically for the I2S
  audio, microSD SPI bus, motor-encoder, and audio-power-amp exclusions)
- CNX Software CYOBot v2 spec listing ("2x buttons"; "33x NeoPixel LED
  matrix" + "12x NeoPixel LED ring")
- github.com/espressif/arduino-esp32 PR #10947 (vendor BUTTON0/BUTTON1 and
  NEO_BRAIN/NEO_BASE pins_arduino.h data pins)

Per-pin findings:
- GPIO8,9,16,45: excluded entirely from chipGpios - dedicated onboard I2S
  audio (per vendor pins_arduino.h).
- GPIO10,11,12,13,14: excluded entirely from chipGpios - dedicated onboard
  microSD SPI bus (per vendor pins_arduino.h).
- GPIO19,20,39,40: excluded entirely from chipGpios - dedicated onboard
  motor encoders (per vendor pins_arduino.h).
- GPIO25: excluded entirely from chipGpios - dedicated onboard audio
  power-amp enable (per vendor pins_arduino.h).
- GPIO4: tagged "button" - confirmed by CNX Software CYOBot v2 spec
  listing ("2x buttons") matching vendor BUTTON0 pins_arduino.h
  (github.com/espressif/arduino-esp32 PR #10947). Capabilities:
  ["digital_input", "button"].
- GPIO38: tagged "button" - same source, matching vendor BUTTON1
  pins_arduino.h. Capabilities: ["digital_input", "button"].
- GPIO7: tagged "led_neopixel" - confirmed by CNX Software CYOBot v2 spec
  listing ("33x NeoPixel LED matrix") matching vendor NEO_BRAIN
  pins_arduino.h data pin. Capabilities: ["digital_output", "led_neopixel",
  "pwm_output"].
- GPIO15: tagged "led_neopixel" - confirmed by CNX Software CYOBot v2 spec
  listing ("12x NeoPixel LED ring") matching vendor NEO_BASE pins_arduino.h
  data pin. Capabilities: ["digital_output", "led_neopixel", "pwm_output"].
- GPIO0,1,2,3,5,6: no tag - standard capabilities ["analog_input",
  "digital_input", "digital_output", "pwm_output"] (GPIO0 kept as
  ["digital_input", "digital_output", "pwm_output"] without analog_input
  in the source board.json).
- GPIO17,18: no tag - standard ADC2-range capabilities
  ["analog_input_serial", "digital_input", "digital_output", "pwm_output"].
- GPIO21,41,42,43,44,46,47,48: no tag - standard capabilities
  ["digital_input", "digital_output", "pwm_output"].

Summary: GPIO8/9/16/45 (I2S audio), GPIO10-14 (microSD SPI), GPIO19/20/39/40
(motor encoders), and GPIO25 (audio power-amp enable) excluded; GPIO4/38
tagged button (BUTTON0/BUTTON1), GPIO7/15 tagged led_neopixel (NeoPixel
matrix/ring) - all confirmed via the CNX Software spec listing matched
against vendor pins_arduino.h from espressif/arduino-esp32 PR #10947.
