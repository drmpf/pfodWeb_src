Board: FoBE Quill ESP32S3 Mesh (ESP32-S3 Dev Module variant)
Date: 2026-07-14 (documentation backfill — findings from an earlier audit pass, not new research)

Sources consulted:
- vendor pins_arduino.h - basis for excluding GPIO1 (peripheral
  power-enable), GPIO12-14 (OLED I2C+enable), GPIO39-46 (SX126x LoRa radio
  SPI+control); also source of the LED_BUILTIN alias matching GPIO11.
- docs.fobestudio.com/quill_esp32s3_mesh_getting_started - confirmed "USR
  Button GPIO0 Low" (active-low, dedicated onboard button) and "USR LED
  GPIO11 Low" (blue LED, active-low, dedicated onboard).

Per-pin findings:
- GPIO0: capabilities [digital_input, button] - tagged "button". Confirmed
  FoBE Studio docs (docs.fobestudio.com/quill_esp32s3_mesh_getting_started):
  "USR Button GPIO0 Low" (active-low, dedicated onboard button).
- GPIO1: excluded (removed from chipGpios entirely) - peripheral
  power-enable, per vendor pins_arduino.h.
- GPIO2, GPIO3, GPIO4, GPIO5, GPIO6, GPIO7, GPIO8, GPIO9, GPIO10:
  capabilities [analog_input, digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO11: capabilities [digital_output, led_low, pwm_output] - tagged
  "led_low". Confirmed FoBE Studio docs
  (docs.fobestudio.com/quill_esp32s3_mesh_getting_started): "USR LED
  GPIO11 Low" (blue LED, active-low, dedicated onboard, matches
  LED_BUILTIN in pins_arduino.h).
- GPIO12, GPIO13, GPIO14: excluded (removed from chipGpios entirely) -
  OLED I2C+enable, per vendor pins_arduino.h.
- GPIO15, GPIO16, GPIO17, GPIO18: capabilities [analog_input_serial,
  digital_input, digital_output, pwm_output] - generic, no tag.
- GPIO21: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO38: capabilities [digital_input, digital_output, pwm_output] -
  generic, no tag.
- GPIO39-GPIO46: excluded (removed from chipGpios entirely) - SX126x LoRa
  radio SPI+control, per vendor pins_arduino.h.
- GPIO47, GPIO48: capabilities [digital_input, digital_output, pwm_output]
  - generic, no tag.

Summary: Excluded the peripheral power-enable pin (GPIO1), OLED I2C+enable
(GPIO12-14), and SX126x LoRa radio SPI+control (GPIO39-46) per vendor
pins_arduino.h; tagged GPIO0 as "button" (USR Button, active-low) and
GPIO11 as "led_low" (USR LED, blue, active-low), both confirmed via FoBE
Studio's official getting-started docs.
